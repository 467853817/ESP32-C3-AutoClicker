# ESP32-C3-AutoClicker

ESP32-C3 SuperMini BLE iPhone 多点轮流连点器

## 功能
- 支持**多点轮流点击**（可配置多个坐标）
- 可自定义点击频率
- 使用绝对坐标，先快速移动到位置再点击
- 代码内有清晰中文注释，方便自己修改

## 使用方法
1. 打开 `src/main.cpp`
2. 修改顶部【用户配置区域】：
   - `CLICK_INTERVAL_MS`：点击间隔（毫秒）
   - `SCREEN_WIDTH` / `SCREEN_HEIGHT`：手机分辨率（iPhone 12 已默认填好 1170x2532）
   - `clickPoints[]`：要点击的坐标列表
3. 编译并烧录到 ESP32-C3
4. 手机打开蓝牙，连接设备名 **ESP32-C3-AutoClicker**
5. 开启 **辅助触控**（设置 → 辅助功能 → 触控 → 辅助触控）

## iPhone 12 如何方便获取坐标

推荐方法（最简单）：
1. 先烧录一次固件并连接手机，打开辅助触控
2. 用手指把指针（小圆点）拖到你想点的位置
3. 截一张图，用电脑打开截图，看图片像素坐标（左上角是 0,0）
4. 或者用以下快捷方式：
   - 打开备忘录 / 任意全屏App
   - 用辅助触控的「手势」或直接拖动指针到目标位置后截图查看

也可以告诉我大概想点的位置（比如「屏幕中间」「底部按钮」），我可以帮你估算坐标。

## 注意事项
- 必须开启辅助触控，否则点击无效
- iOS 18+ 绝对坐标效果最好
- 如果点击位置有偏差，可微调 `clickPoints` 里的数字
